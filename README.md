## Как опубликовать

1. На github.com → **New repository**. Имя: `SpaceHabit`. Public. Галочка «Add a README file».
2. В репозитории: **Add file → Upload files** → перетащить `index.html` и `privacy.html` →
   **Commit changes**.
   Перед перетаскиванием проверь имена файлов: браузер любит дописывать `(1)` или `_1`.
   Должно быть ровно `index.html` и `privacy.html`.
3. **Settings → Pages** → Source: *Deploy from a branch* → Branch: `main`, папка `/ (root)` → **Save**.
4. Через 1–3 минуты сайт открывается по адресу
   `https://ИМЯ_АККАУНТА.github.io/SpaceHabit/`, политика —
   `https://ИМЯ_АККАУНТА.github.io/SpaceHabit/privacy.html`

Имя аккаунта в адресе пишется маленькими буквами, название репозитория — ровно так,
как в репозитории (`SpaceHabit`, с большими S и H).

## Куда вставить ссылку в Play Console

**App content → Privacy policy** → ссылка на `privacy.html` → Save.
Ту же ссылку обычно кладут и в **Store listing → Контактные данные**, рядом с почтой.

## Data safety для этого приложения

Собираемых данных нет, кроме одной строки — **Финансовые сведения → История покупок**:
её Google просит указывать всем, кто использует Play Billing. Ответы по ней:
собирается (не передаётся), не временно, пользователь может отказаться,
цель — только функциональность приложения.

Идентификаторы пользователя и устройства **не** отмечать: ни аналитики, ни Firebase,
ни рекламы в приложении нет.
